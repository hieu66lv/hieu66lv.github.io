API Documentation

Tài liệu hướng dẫn tích hợp TempBox API — proxy miễn phí cho dịch vụ email tạm thời. Không cần API key, không cần đăng ký.

Tổng quan

TempBox cung cấp proxy API cho 2 provider email tạm thời. Tất cả request đều đi qua proxy server để tránh CORS và bảo vệ privacy.

ProviderPrefixAuthĐặc điểm
Mail.tm/api/mailtm/*JWT TokenREST chuẩn, cần tạo account
Guerrilla Mail/api/guerrilla?...Session tokenĐơn giản, chỉ GET request

Base URL

https://tempbox-email.netlify.app

Tất cả endpoint bên dưới đều relative với base URL này.

Xác thực

Mail.tm: Sử dụng JWT Bearer token trong header Authorization.

Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

Guerrilla Mail: Sử dụng sid_token trong query parameter. Token được trả về từ request đầu tiên.

Rate Limits

ProviderLimitWindow
Mail.tm8 requests1 giây / IP
Guerrilla Mail~10 requests1 giây
💡

Khi vượt rate limit, server trả về 429 Too Many Requests. Hãy implement exponential backoff.

Xử lý lỗi

API trả về HTTP status code chuẩn:

CodeÝ nghĩa
200Thành công
201Tạo thành công (POST)
401Token hết hạn hoặc không hợp lệ
404Không tìm thấy resource
422Dữ liệu không hợp lệ
429Vượt rate limit

Mail.tm API

Quy trình sử dụng: Lấy domain → Tạo account → Lấy token → Đọc email

Lấy danh sách domain

GET /api/mailtm/domains?page=1

Trả về danh sách domain khả dụng để tạo email.

Parameters

ParamTypeMô tả
pageintegerSố trang (mặc định: 1)

Response 200

{
  "hydra:member": [
    {
      "id": "abc123",
      "domain": "wshu.net",
      "isActive": true,
      "createdAt": "2026-01-01T00:00:00+00:00"
    }
  ]
}

Tạo tài khoản email

POST /api/mailtm/accounts

Tạo một địa chỉ email mới. Domain phải lấy từ endpoint trên.

Request Body

FieldTypeRequiredMô tả
addressstring✓Địa chỉ email (phải dùng domain hợp lệ)
passwordstring✓Mật khẩu (tối thiểu 6 ký tự)
 
{
  "address": "myuser@wshu.net",
  "password": "securepass123"
}

Response 201

{
  "id": "/accounts/abc123def",
  "address": "myuser@wshu.net",
  "createdAt": "2026-05-31T10:00:00+00:00"
}

Lấy token xác thực

POST /api/mailtm/token

Đăng nhập bằng email + password để nhận JWT token.

Request Body

{
  "address": "myuser@wshu.net",
  "password": "securepass123"
}

Response 200

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "id": "/accounts/abc123def"
}
🔑

Token có thời hạn. Khi nhận 401, gọi lại endpoint này để refresh token.

Xóa email

Xóa một email khỏi inbox. Yêu cầu xác thực.

Guerrilla Mail API

Guerrilla Mail sử dụng một endpoint duy nhất với query parameter f để xác định action. Đơn giản hơn Mail.tm — chỉ cần GET request.

💡

Luôn lưu lại sid_token từ response và gửi kèm trong các request tiếp theo để duy trì session.

Tạo email mới

GET /api/guerrilla?f=get_email_address

Tạo một địa chỉ email ngẫu nhiên và khởi tạo session.

Ví dụ tích hợp

Code mẫu cho các ngôn ngữ phổ biến.

const BASE = 'https://tempbox-email.netlify.app';

// ═══════════════════════════════════════════
// Mail.tm — Full workflow
// ═══════════════════════════════════════════
async function createMailTm() {
  // 1. Lấy domain khả dụng
  const domains = await fetch(`${BASE}/api/mailtm/domains?page=1`)
    .then(r => r.json());
  const domain = domains['hydra:member'][0].domain;

  // 2. Tạo account
  const address = `user${Date.now()}@${domain}`;
  const password = 'MySecurePass123';

  await fetch(`${BASE}/api/mailtm/accounts`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ address, password })
  });

  // 3. Lấy JWT token
  const { token } = await fetch(`${BASE}/api/mailtm/token`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ address, password })
  }).then(r => r.json());

  // 4. Đọc inbox
  const inbox = await fetch(`${BASE}/api/mailtm/messages?page=1`, {
    headers: { 'Authorization': `Bearer ${token}` }
  }).then(r => r.json());

  console.log('📧 Email:', address);
  console.log('📬 Messages:', inbox['hydra:member']);
  return { address, token };
}

// ═══════════════════════════════════════════
// Guerrilla Mail — Simple workflow
// ═══════════════════════════════════════════
async function createGuerrilla() {
  // 1. Tạo email
  const { email_addr, sid_token } = await fetch(
    `${BASE}/api/guerrilla?f=get_email_address`
  ).then(r => r.json());

  // 2. Kiểm tra inbox (polling)
  const check = await fetch(
    `${BASE}/api/guerrilla?f=check_email&seq=0&sid_token=${sid_token}`
  ).then(r => r.json());

  console.log('📧 Email:', email_addr);
  console.log('📬 Messages:', check.list);
  return { email_addr, sid_token: check.sid_token };
}
import requests
import time

BASE = "https://tempbox-email.netlify.app"

# ═══════════════════════════════════════════
# Mail.tm
# ═══════════════════════════════════════════
def create_mailtm():
    # 1. Lấy domain
    domains = requests.get(f"{BASE}/api/mailtm/domains?page=1").json()
    domain = domains["hydra:member"][0]["domain"]

    # 2. Tạo account
    address = f"user{int(time.time())}@{domain}"
    password = "MySecurePass123"

    requests.post(f"{BASE}/api/mailtm/accounts",
                  json={"address": address, "password": password})

    # 3. Lấy token
    token_res = requests.post(f"{BASE}/api/mailtm/token",
                              json={"address": address, "password": password})
    token = token_res.json()["token"]

    # 4. Đọc inbox
    headers = {"Authorization": f"Bearer {token}"}
    inbox = requests.get(f"{BASE}/api/mailtm/messages?page=1",
                         headers=headers).json()

    print(f"📧 Email: {address}")
    print(f"📬 Messages: {inbox.get('hydra:member', [])}")
    return address, token

# ═══════════════════════════════════════════
# Guerrilla Mail
# ═══════════════════════════════════════════
def create_guerrilla():
    # 1. Tạo email
    data = requests.get(f"{BASE}/api/guerrilla",
                        params={"f": "get_email_address"}).json()
    email = data["email_addr"]
    sid = data["sid_token"]

    # 2. Kiểm tra inbox
    inbox = requests.get(f"{BASE}/api/guerrilla",
                         params={"f": "check_email", "seq": "0",
                                 "sid_token": sid}).json()

    print(f"📧 Email: {email}")
    print(f"📬 Messages: {inbox.get('list', [])}")
    return email, inbox.get("sid_token", sid)

if __name__ == "__main__":
    create_mailtm()
    create_guerrilla()

# ═══════════════════════════════════════════
# Mail.tm
# ═══════════════════════════════════════════

# Lấy domain
curl "https://tempbox-email.netlify.app/api/mailtm/domains?page=1"

# Tạo account
curl -X POST "https://tempbox-email.netlify.app/api/mailtm/accounts" \
  -H "Content-Type: application/json" \
  -d '{"address":"test@wshu.net","password":"secret123"}'

# Lấy token
curl -X POST "https://tempbox-email.netlify.app/api/mailtm/token" \
  -H "Content-Type: application/json" \
  -d '{"address":"test@wshu.net","password":"secret123"}'

# Đọc inbox (thay YOUR_TOKEN bằng token thật)
curl "https://tempbox-email.netlify.app/api/mailtm/messages?page=1" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Đọc email cụ thể
curl "https://tempbox-email.netlify.app/api/mailtm/messages/MSG_ID" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Xóa email
curl -X DELETE "https://tempbox-email.netlify.app/api/mailtm/messages/MSG_ID" \
  -H "Authorization: Bearer YOUR_TOKEN"
⚠️

Lưu ý quan trọng:

  • Email tạm thời có thể bị xóa bất kỳ lúc nào — không dùng cho tài khoản quan trọng
  • Tuân thủ rate limit của từng provider
  • Không sử dụng cho mục đích spam hoặc bất hợp pháp
  • Nội dung email không được mã hóa — không gửi thông tin nhạy cảm
