Hướng dẫn tích hợp API

TempBox cung cấp proxy API miễn phí cho 2 dịch vụ email tạm thời. Không cần API key, không cần đăng ký. Tích hợp vào ứng dụng của bạn chỉ trong vài phút.

Mail.tm API

Mail.tm sử dụng REST API chuẩn. Quy trình: lấy domain → tạo account → lấy token → đọc email.

Lấy danh sách domain

GET /api/mailtm/domains?page=1

Trả về danh sách domain có thể dùng để tạo email.

Response: 
{
  "hydra:member": [
    {
      "id": "abc123",
      "domain": "wshu.net",
      "isActive": true
    }
  ]
}

Tạo tài khoản email

POST /api/mailtm/accounts

Tạo một địa chỉ email mới. address phải dùng domain từ bước trên.

Request Body: 
{
  "address": "tenban@wshu.net",
  "password": "matkhau_batky"
}
Response: 201 Created 
{
  "id": "/accounts/abc123",
  "address": "tenban@wshu.net"
}

Lấy token xác thực

POST /api/mailtm/token

Dùng email + password vừa tạo để lấy JWT token.

Request Body: 
{
  "address": "tenban@wshu.net",
  "password": "matkhau_batky"
}
Response: 
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "id": "/accounts/abc123"
}
💡 Dùng token này trong header Authorization: Bearer <token> cho các request tiếp theo.

Lấy danh sách email

GET /api/mailtm/messages?page=1

Yêu cầu header: Authorization: Bearer <token>

Response: 
{
  "hydra:member": [
    {
      "id": "msg_id",
      "from": { "name": "Facebook", "address": "no-reply@fb.com" },
      "subject": "Mã xác minh: 123456",
      "intro": "Mã của bạn là 123456...",
      "seen": false,
      "createdAt": "2026-05-31T10:00:00+00:00"
    }
  ]
}

Đọc nội dung email

GET /api/mailtm/messages/{id}

Yêu cầu header: Authorization: Bearer <token>

Response: 
{
  "id": "msg_id",
  "from": { "name": "Facebook", "address": "no-reply@fb.com" },
  "subject": "Mã xác minh",
  "text": "Mã của bạn là 123456",
  "html": ["<html>...</html>"],
  "createdAt": "2026-05-31T10:00:00+00:00"
}

Guerrilla Mail API

Guerrilla Mail đơn giản hơn — chỉ cần GET request với query params. Lưu sid_token để dùng cho các request tiếp theo.

Tạo email mới

GET /api/guerrilla?f=get_email_address

Tạo một địa chỉ email ngẫu nhiên.

Response: 
{
  "email_addr": "abc123@guerrillamailblock.com",
  "email_timestamp": 1780168629,
  "sid_token": "session_token_day"
}
💡 Lưu sid_token — cần dùng cho mọi request tiếp theo.

Kiểm tra hộp thư

GET /api/guerrilla?f=check_email&seq=0&sid_token=TOKEN

Kiểm tra email mới. seq là sequence number (dùng 0 để lấy tất cả).

Response: 
{
  "list": [
    {
      "mail_id": "12345",
      "mail_from": "no-reply@example.com",
      "mail_subject": "Verify your account",
      "mail_excerpt": "Your code is...",
      "mail_timestamp": "1780168700",
      "mail_read": "0"
    }
  ],
  "sid_token": "updated_token"
}

Đọc nội dung email

GET /api/guerrilla?f=fetch_email&email_id=ID&sid_token=TOKEN
Response: 
{
  "mail_id": "12345",
  "mail_from": "no-reply@example.com",
  "mail_subject": "Verify your account",
  "mail_body": "<html>Your code is 654321</html>",
  "mail_date": "2026-05-31 10:00:00"
}

Đổi tên email

GET /api/guerrilla?f=set_email_user&email_user=TENBAN&sid_token=TOKEN

Đổi phần trước @ thành tên bạn muốn.

Response: 
{
  "email_addr": "tenban@guerrillamailblock.com",
  "sid_token": "updated_token"
}

Ví dụ: JavaScript

// === Mail.tm: Tạo email + đọc inbox ===
async function demoMailTm() {
  // 1. Lấy domain
  const domains = await fetch('/api/mailtm/domains?page=1').then(r => r.json());
  const domain = domains['hydra:member'][0].domain;

  // 2. Tạo account
  const address = 'user' + Date.now() + '@' + domain;
  const password = 'Pass1234';
  await fetch('/api/mailtm/accounts', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ address, password })
  });

  // 3. Lấy token
  const { token } = await fetch('/api/mailtm/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ address, password })
  }).then(r => r.json());

  // 4. Đọc inbox
  const inbox = await fetch('/api/mailtm/messages?page=1', {
    headers: { 'Authorization': 'Bearer ' + token }
  }).then(r => r.json());

  console.log('📧 Email:', address);
  console.log('📬 Inbox:', inbox['hydra:member']);
}

// === Guerrilla Mail: Đơn giản hơn ===
async function demoGuerrilla() {
  // 1. Tạo email
  const data = await fetch('/api/guerrilla?f=get_email_address').then(r => r.json());
  const { email_addr, sid_token } = data;

  // 2. Kiểm tra inbox
  const inbox = await fetch(
    '/api/guerrilla?f=check_email&seq=0&sid_token=' + sid_token
  ).then(r => r.json());

  console.log('📧 Email:', email_addr);
  console.log('📬 Inbox:', inbox.list);
}

Ví dụ: Python

import requests

BASE = "http://localhost:3000"

# === Mail.tm ===
def demo_mailtm():
    # Lấy domain
    domains = requests.get(f"{BASE}/api/mailtm/domains?page=1").json()
    domain = domains["hydra:member"][0]["domain"]

    # Tạo account
    address = f"test123@{domain}"
    password = "MyPass123"
    requests.post(f"{BASE}/api/mailtm/accounts",
                  json={"address": address, "password": password})

    # Lấy token
    token_data = requests.post(f"{BASE}/api/mailtm/token",
                               json={"address": address, "password": password}).json()
    token = token_data["token"]

    # Đọc inbox
    headers = {"Authorization": f"Bearer {token}"}
    inbox = requests.get(f"{BASE}/api/mailtm/messages?page=1", headers=headers).json()
    print(f"Email: {address}")
    print(f"Messages: {inbox.get('hydra:member', [])}")

# === Guerrilla Mail ===
def demo_guerrilla():
    # Tạo email
    data = requests.get(f"{BASE}/api/guerrilla?f=get_email_address").json()
    email = data["email_addr"]
    sid = data["sid_token"]

    # Kiểm tra inbox
    inbox = requests.get(f"{BASE}/api/guerrilla?f=check_email&seq=0&sid_token={sid}").json()
    print(f"Email: {email}")
    print(f"Messages: {inbox.get('list', [])}")

demo_mailtm()
demo_guerrilla()

Ví dụ: cURL

# Guerrilla Mail — tạo email
curl "http://localhost:3000/api/guerrilla?f=get_email_address"

# Guerrilla Mail — kiểm tra inbox
curl "http://localhost:3000/api/guerrilla?f=check_email&seq=0&sid_token=YOUR_TOKEN"

# Mail.tm — lấy domain
curl "http://localhost:3000/api/mailtm/domains?page=1"

# Mail.tm — tạo account
curl -X POST "http://localhost:3000/api/mailtm/accounts" \
  -H "Content-Type: application/json" \
  -d '{"address":"test@wshu.net","password":"secret123"}'

# Mail.tm — lấy token
curl -X POST "http://localhost:3000/api/mailtm/token" \
  -H "Content-Type: application/json" \
  -d '{"address":"test@wshu.net","password":"secret123"}'

# Mail.tm — đọc inbox
curl "http://localhost:3000/api/mailtm/messages?page=1" \
  -H "Authorization: Bearer YOUR_TOKEN"
⚠️ Lưu ý quan trọng:
  • Email tạm thời có thể bị xóa bất kỳ lúc nào — không dùng cho việc quan trọng
  • Server proxy chỉ chạy local (localhost:3000)
  • Tuân thủ rate limit của từng provider
  • Không dùng cho mục đích bất hợp pháp
